## 认证通用基础

### 一、合格评定基础知识

#### 1.1 合格评定基本概念

| 知识点 | 核心内容 | 教材位置 |
|--------|----------|----------|
| 合格评定定义 | 规定要求得到满足的证实 | 《合格评定基础》P1 |
| 合格评定活动 | 认证、认可、检验、检测、校准 | 《合格评定基础》P5-10 |
| 合格评定对象 | 产品、过程、体系、人员、机构 | 《合格评定基础》P3 |
| 合格评定依据 | 标准、技术规范、法律法规 | 《合格评定基础》P4 |

#### 1.2 合格评定原则

| 原则 | 含义 |
|------|------|
| 非歧视原则 | 平等对待所有合格评定对象 |
| 遵守国际标准原则 | 采用国际通行标准和方法 |
| 统一原则 | 保持评定标准和程序的一致性 |
| 透明度原则 | 公开评定规则和结果 |
| 协调一致原则 | 各评定活动相互协调 |
| 有限干预原则 | 政府干预最小化 |

#### 1.3 国家质量基础设施（NQI）

| 要素 | 作用 |
|------|------|
| 计量 | 解决准确测量问题 |
| 标准 | 提供技术依据 |
| 合格评定 | 判定是否符合标准 |

#### 1.4 合格评定功能法

| 功能环节 | 内容 |
|----------|------|
| 选取 | 确定合格评定对象 |
| 确定 | 获取并评价证据 |
| 复核与证明 | 确认符合性并出具证明 |
| 监督 | 保持符合性的持续验证 |

### 二、审核通用知识

#### 2.1 审核基本概念

| 知识点 | 核心内容 | 教材位置 |
|--------|----------|----------|
| 审核定义 | 为获得客观证据并对其进行客观评价 | 《审核概论》P1 |
| 审核原则 | 诚实正直、公正表达、职业素养、保密性、独立性、基于证据、基于风险 | 《审核概论》P13 |
| 审核类型 | 内部审核、外部审核、结合审核、联合审核 | 《审核概论》P8-12 |

#### 2.2 审核方案管理

| 知识点 | 核心内容 |
|--------|----------|
| 审核方案定义 | 针对特定时间段所策划的一组审核 |
| 审核方案内容 | 目标、范围、准则、方法、时间、资源 |
| 审核方案管理 | 建立、实施、评审、改进 |

#### 2.3 审核活动

| 阶段 | 主要活动 |
|------|----------|
| 审核启动 | 指定审核组长、确定审核目的范围 |
| 审核准备 | 编制审核计划、文件评审 |
| 审核实施 | 开次会议、现场审核、末次会议 |
| 审核报告 | 编制、批准、分发 |
| 后续活动 | 纠正措施验证 |

#### 2.4 审核技术

| 技术 | 应用场景 |
|------|----------|
| 抽样技术 | 选取有代表性的样本 |
| 检查表 | 确保审核覆盖完整 |
| 面谈 | 获取信息 |
| 文件评审 | 验证符合性 |
| 现场观察 | 获取客观证据 |

#### 1.1 环境管理体系基础

| 环境方针 | 组织环境绩效的总体意图和方向 |
